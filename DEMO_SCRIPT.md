# ASTRAGUARD — 5 Minute Demo Script

## 1. The Problem (30 seconds)
Emergency evacuations are planned under pressure.
Data is incomplete. Conditions change.
Wrong decisions cost lives.

Most systems:
• are static
• trust black-box AI
• fail when reality changes

---

## 2. The System (1 minute)
ASTRAGUARD is an intelligent evacuation decision system.

It combines:
• AI predictions
• physical safety rules
• scenario simulation
• human oversight

AI never decides alone.

---

## 3. Live Demo (2 minutes)
• Load evacuation routes
• Show baseline recommendation
• Increase congestion using slider
• Show route recommendation change
• Highlight confidence drop
• Show human approval warning

Explain:
“The system adapts before the situation becomes dangerous.”

---

## 4. Why This Matters (1 minute)
ASTRAGUARD:
• never underestimates evacuation time
• blocks unsafe recommendations
• works even with partial data
• preserves human authority

This is decision support — not automation.

---

## 5. Closing (30 seconds)
ASTRAGUARD helps authorities make
safer decisions when it matters most.

This is not a model.
It is a system built for reality.
