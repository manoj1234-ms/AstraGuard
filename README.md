# 🛡️ ASTRAGUARD

**ASTRAGUARD** is an intelligent evacuation decision-support system designed for
emergency authorities operating under uncertainty.

It combines **AI predictions**, **safety rules**, and **scenario simulation**
to produce **safe, explainable, and adaptive evacuation plans**.

---

## 🚨 The Problem
During disasters:
- Data is incomplete
- Conditions change rapidly
- Decisions are made under pressure

Static plans and black-box AI models fail in real-world chaos.

---

## ✅ The Solution
ASTRAGUARD:
- Predicts evacuation time using ML
- Enforces physical safety constraints
- Simulates worst-case scenarios
- Requires human approval for risky decisions
- Never underestimates evacuation time

This makes decisions **trustworthy**, not just fast.

---

## 🧠 How It Works (High Level)

Data → Scenario Engine → ML Prediction  
→ Safety & Rule Layer → Human Approval  
→ Final Evacuation Recommendation

---

## 🔍 Key Features
- AI + rule-based decision system
- Scenario stress testing (congestion, capacity loss)
- Confidence-aware recommendations
- Human-in-the-loop control
- Zone-level evacuation planning
- Offline & degraded mode ready

---

## 🧱 Technology Moat
- Safety rules override AI predictions
- Decisions are scenario-aware, not static
- Explainability is built-in
- Designed for real-world constraints
